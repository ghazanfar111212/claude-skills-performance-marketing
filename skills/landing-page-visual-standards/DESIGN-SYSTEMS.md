# Approved Design Systems

Pick one per page, or derive a new system from the subject's world. Never mix systems on one page. In every system: the ACCENT is the CTA color and appears nowhere else.

## System 1 - "Evidence File" (approved on the AEO page)
Editorial, factual, slightly forensic. Best for: audits, B2B offers, anything where proof is the pitch.
- Palette: bone `#EDEEE5` · deep bone `#E3E5D8` · ink `#151812` · pine `#17392C` (dark blocks) · ACCENT signal orange `#FF4D00`
- Type: Fraunces (display, use italic moments) · Archivo (body) · Fragment Mono (labels, queries, data)
- Devices: citation-index section markers `[01]`, hairline rules, mono metadata, rotated stamp, receipt-style summaries
- Reference: `examples/aeo-evidence-file.html`

## System 2 - "Clinical Warm" 
Trustworthy, calm, premium-medical. Best for: dental, clinics, healthcare, wellness offers.
- Palette: warm white `#FBF9F6` · porcelain `#F1EDE6` · deep teal ink `#123A3A` · soft sage `#DCE5DD` (section tint) · ACCENT coral-red `#E8503A`
- Type: Canela-alternative → "Newsreader" (display, light weights, large sizes) · "Public Sans" (body) · "Spline Sans Mono" (data/labels)
- Devices: generous whitespace, thin arched/rounded photo masks, small-caps labels, before/after treatment framing, review stars rendered as type not icons

## System 3 - "Site Plan"
Sturdy, built, blueprint energy. Best for: hardscaping, home services, contractors, construction-adjacent.
- Palette: paper grey `#EDEDEA` · graphite `#1C1E1C` · safety yellow `#F5C400` blocks · ACCENT construction orange `#E85D04` (if yellow used for blocks, CTA can be graphite-on-yellow - still one loud pairing only)
- Type: "Archivo Expanded/Black" (display, uppercase, tight) · "Archivo" (body) · "IBM Plex Mono" (measurements, specs)
- Devices: dimension-line rules with end ticks, spec-sheet tables, big project photos full-bleed, phase numbering that reflects a real build sequence

## System 4 - "Terminal Report"
Technical, sharp, operator-grade. Best for: SaaS, dev tools, apps/ASO, cybersecurity, data offers.
- Palette: carbon `#101418` · panel `#171C22` · fog text `#C6CDD5` · grid line `rgba(198,205,213,.14)` · ACCENT amber `#FFB020` (NOT acid green - that's the flagged cliché)
- Type: "Sora" or "Schibsted Grotesk" (display) · "Inter is BANNED - use "Atkinson Hyperlegible" or "Public Sans" (body) · "JetBrains Mono" (code, metrics)
- Devices: log-line entries, status chips, live-metric counters, keyboard-key styling for feature names, scanline restraint (no matrix effects)

## Deriving a new system (when none fit)
1. Name 3 physical artifacts from the subject's world (dental: x-ray film, appointment card, porcelain).
2. Pull palette from those artifacts, not from color theory.
3. Pick a display face with genuine character (Fraunces, Newsreader, Bricolage Grotesque, Instrument Serif, Archivo Expanded, Unbounded - sparingly) + a quiet body + a mono for data.
4. Invent the signature element from artifact #1.
5. Verify against the banned list in SKILL.md before building.
