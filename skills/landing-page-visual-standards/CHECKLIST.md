# Pre-Delivery Self-Critique

Run every item before presenting the page. If any item fails, fix it first - do not present with caveats.

## The slop test
- [ ] Could this exact page be generated for ANY other business by swapping nouns? If yes → the design isn't grounded in the subject. Rework the signature element.
- [ ] Cover the logo: can you still tell what industry/offer this is from the visuals alone?
- [ ] Zero banned-list violations (fonts, colors, layouts, copy patterns - see SKILL.md).
- [ ] The signature element exists, is unique to this subject, and appears above the fold.
- [ ] At least one typographic moment with personality (italic emphasis, strike-through, oversized numeral, mono interruption).

## The 5-second test (from landing-page-designer)
- [ ] What is offered, who it's for, why care, what to do next - all clear without scrolling.
- [ ] Headline states an outcome with specificity, not a category description.

## Conversion mechanics
- [ ] Exactly one CTA color; it appears only on CTAs; nothing else on the page competes with it.
- [ ] Offer repeated 3x + sticky mobile CTA present.
- [ ] Form ≤4 fields, includes the qualifying dropdown, friction-removal line under CTA ("no call / no card").
- [ ] Every claim on the page is defensible today. No invented logos, stats, or testimonials.
- [ ] FAQ pre-handles the offer's real objections (price, timeline, "is this legit", measurement).

## Craft floor
- [ ] Mobile: single column, ≥16px body, 44px tap targets, no horizontal scroll, CTA above fold.
- [ ] `prefers-reduced-motion` respected on every animation; max 2 living details total.
- [ ] Visible keyboard focus on inputs and buttons.
- [ ] One Google Fonts link tag; no external JS libraries; single self-contained file.
- [ ] `<!-- GHL FORM EMBED SLOT -->` comment marks the form.

## Final mirror check
- [ ] Remove one accessory: identify the least-necessary decorative element and delete it.
- [ ] Read every line of copy aloud: cut anything a real founder wouldn't say to a client's face.
