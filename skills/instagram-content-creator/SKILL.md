# Instagram Content Creator

Reels-first Instagram content built on two pillars: **live trend research** (what's working right now) and **gap detection** (what the audience wants that nobody in the niche is making well). The output is not "content ideas" - it's ready-to-shoot production packages a creator can film the same day.

## Step 0: Intake

Establish before researching (ask ONE compact question if genuinely missing; otherwise infer and state assumptions):

- **Niche + who's posting** - a personal brand, a business account, a faceless page? This changes format feasibility (talking-head vs b-roll+text vs voiceover).
- **Goal** - followers/reach, leads, sales, authority? Determines CTA style and content mix.
- **Volume** - one Reel, a batch, or a calendar?

Scale to the ask: "write me a reel script about X" = skip research-heavy gap analysis, do a light trend check (2 - 3 searches), deliver one great package. "Find gaps in [niche] and build me content" = full pipeline below.

## Step 1: Live trend + gap research

Never generate from stale knowledge alone - trends on IG rot in weeks. Research first (4 - 10 searches depending on scope):

**What's working now (trend layer):**
- `[niche] instagram reels trending 2026`, `[niche] viral reels`, `instagram reels trends [current month/year]`
- `[niche] tiktok trending` - TikTok leads, IG follows by 2 - 6 weeks; TikTok trends are tomorrow's Reels trends
- Trending audio/formats: `trending instagram audio this week`, `reels trends this week`

**What the audience actually wants (demand layer):**
- `[niche] reddit` + common questions - real pain points in real language
- `[niche]` + "how to", "why does", "beginner mistakes" - the question landscape
- YouTube search for the niche - high-view video topics = proven demand that often hasn't been compressed into Reels yet

**What creators are supplying (supply layer):**
- `top [niche] instagram accounts`, `[niche] instagram creators` - identify 3 - 6 dominant accounts and note their recurring formats and topics

**The gap = demand layer minus supply layer.** A gap is real when you can point at both sides: "audiences repeatedly ask X (Reddit/comments evidence) and the top accounts post almost exclusively Y (observed)." Classic gap shapes to hunt for:
- **Topic gaps** - questions asked everywhere, answered nowhere on IG
- **Format gaps** - niche is all aesthetic b-roll but no one does tutorials; or all talking-heads but no one does POV/skits
- **Audience-segment gaps** - everyone targets beginners, nobody serves intermediates; or everyone targets consumers, nobody talks to pros
- **Angle gaps** - everyone is positive/salesy; no myth-busting, no "what I'd never buy," no honest comparisons
- **Depth gaps** - surface-level tips everywhere, no one shows the actual process/numbers/behind-the-scenes

Be honest about data limits: you can't see IG analytics, exact view counts, or the algorithm. Frame trend claims by evidence ("multiple sources report this format surging since [month]") and mark inferences as inferences.

## Step 2: Gap map (for strategy-scope requests)

Present findings compactly before generating content - a short table: gap · type (topic/format/segment/angle/depth) · demand evidence · supply evidence · opportunity strength (Strong/Moderate/Speculative). Lead with the 2 - 3 strongest. This lets the user redirect before you script the wrong things.

## Step 3: Generate content packages

Every idea ships as a full production package. Read **references/reels-playbook.md** before writing scripts - it contains the hook formulas, script frameworks, retention mechanics, and the exact package template.

Core rules that make Reels work (details in the playbook):

- **The hook is 80% of the outcome.** Deliver 3 - 5 hook options per Reel (mix of verbal, text-overlay, and visual hooks). First 1.5 seconds decide everything.
- **Script to time.** Reels scripts carry timestamps (0:00 - 0:02 hook, 0:02 - 0:08 setup...). Target 15 - 35s for reach content, up to 60 - 90s only for high-retention formats (storytime, tutorials).
- **Write for sound-off + sound-on simultaneously** - every spoken line has a text-overlay plan.
- **One Reel, one idea.** Multi-point Reels become carousels instead - recommend the format switch when the idea demands it.
- **Retention beats cleverness** - open loops, pattern interrupts every 3 - 5s, payoff at the end, no intros ever ("hey guys, today I'm going to..." is banned).
- **CTA matched to goal** - follows ("follow for part 2"), saves ("save this for..."), shares ("send this to..."), or DM-keyword lead gen for business accounts.

Each package includes: title/concept · why it fills a gap or rides a trend (one line, evidence-based) · 3 - 5 hooks · timestamped script with text overlays · visual/b-roll shot directions · audio suggestion (trending style, described not fabricated) · caption (hook line + value + CTA) · hashtag set (mixed-size strategy per the playbook) · format alternates if relevant (carousel/story version).

## Step 4: Deliverables by scope

- **Single Reel ask** → one package, in chat, no scaffolding.
- **Batch ask** ("give me 10 reels for...") → gap map first (brief), then packages. For 5+ packages, produce a Markdown file and present it; summarize the top 3 in chat.
- **Strategy/calendar ask** → gap map + content-pillar recommendation (3 - 5 pillars mixing trend-riders, gap-fillers, and evergreen) + posting calendar (asset · pillar · format · gap/trend it targets · goal-stage) + the first week's packages fully scripted. Ship as a file.

## Quality bar

- Every idea traces to observed demand or a live trend - no generic "5 tips" filler unless the research showed it's genuinely underserved.
- Hooks pass the scroll test: would this stop someone mid-scroll who doesn't follow the account? If a hook only works for existing followers, rewrite it.
- Scripts are shootable as written - a creator with a phone should need zero additional planning.
- Language matches the niche's register (a hardscaping contractor's Reel doesn't sound like a skincare influencer's).
