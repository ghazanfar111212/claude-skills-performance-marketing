# Reels Playbook

Hook formulas, script frameworks, retention mechanics, hashtag strategy, and the package template. Read this before scripting.

## 1. Hook formulas

The hook = the first 1 - 1.5 seconds of audio + the first frame's visual + the first text overlay, working together. Always deliver 3 - 5 options mixing these types:

**Verbal/text hook formulas** (fill the brackets with niche specifics):
1. **Negative interrupt** - "Stop doing [common practice]" / "[Popular thing] is ruining your [outcome]"
2. **Specific result** - "How I [specific outcome] in [timeframe] without [common sacrifice]"
3. **Curiosity gap** - "Nobody talks about the real reason [phenomenon]" / "The [niche] industry doesn't want you to know this"
4. **Callout** - "If you're a [specific person] who [specific struggle], watch this"
5. **Contrarian take** - "Unpopular opinion: [sacred cow] is overrated - here's what to do instead"
6. **Mistake framing** - "[N] [niche] mistakes that scream beginner" / "I wasted [money/time] so you don't have to"
7. **Before the payoff** - "Wait for the [result/transformation]" (visual-payoff formats)
8. **Numbered value** - "3 [niche] [tools/tricks/settings] that feel illegal to know"
9. **POV/relatable** - "POV: you finally [relatable moment every niche member knows]"
10. **Challenge/proof** - "I tried [thing] for [duration]. Here's what actually happened"

**Visual hooks** (pair with any verbal hook): start mid-action, show the end result first, unexpected prop/setting, fast movement toward camera, text-only bold claim on a pattern-interrupt background.

Test for every hook: **would a stranger stop scrolling?** Hooks that require knowing the creator ("big announcement!") fail this test.

## 2. Script frameworks

Pick per idea. All scripts use timestamps and include text-overlay notes per beat.

**A. Quick Value (15 - 30s)** - for tips, tools, mistakes. Hook (0 - 2s) → deliver points fast, one per 4 - 6s, each with a visual change → CTA (last 2 - 3s). No transitions, no filler words.

**B. Problem - Agitate - Solve (20 - 40s)** - for pain-point content. Hook names the problem (0 - 2s) → agitate: the cost of the problem, make them feel seen (2 - 8s) → the fix, concrete and demonstrated (8 - end) → CTA.

**C. Tutorial/Process (30 - 90s)** - for how-to. Hook shows the finished result FIRST (0 - 3s) → steps compressed, each step = one shot + one overlay → recap frame → save-CTA ("save this so you don't lose it").

**D. Storytime (45 - 90s)** - for experience/case-study content. Hook = the most dramatic moment or the outcome, stated up front (0 - 3s) → context fast (3 - 10s) → escalation with open loops ("but that's when it got worse") → resolution + lesson → follow-CTA. Highest watch-time format when done well.

**E. Myth-bust / Comparison (20 - 45s)** - for angle-gap content. Hook states the myth or the matchup (0 - 2s) → "here's what's actually true" with proof/demo → verdict → share-CTA ("send this to someone who still believes this").

**F. Silent/aesthetic + text narrative (15 - 30s)** - for faceless pages and visual niches. B-roll sequence with text overlays carrying the entire script; audio = trending sound. Script = overlay sequence + shot list.

## 3. Retention mechanics

- **Pattern interrupt every 3 - 5 seconds**: cut, zoom, angle change, overlay change, prop reveal. Static shots kill retention.
- **Open loops**: tease the best point ("the last one changed everything") to hold viewers through the list.
- **No intros, no outros.** First word = hook. Last word = CTA. Trim ruthlessly.
- **Loop potential**: for short Reels, write the ending to flow back into the beginning - rewatches boost distribution.
- **Sound-off design**: every spoken beat gets an overlay; assume 60%+ watch muted in feed.

## 4. Captions

Structure: **Line 1 = re-hook** (different wording than the video hook - it shows in feed preview) → 2 - 5 short lines of added value or context (bonus tip, the "why", or the story detail that didn't fit) → **CTA** (one, matched to goal) → hashtags. Line breaks between every line; no walls of text. For business/lead-gen accounts, DM-keyword CTAs ("Comment SYSTEM and I'll send it") outperform link-in-bio asks.

## 5. Hashtag strategy

Hashtags are a minor ranking signal in 2026 - topical relevance of the content itself matters far more - but they still aid categorization. Use 3 - 8 per post, mixed sizes:
- 1 - 2 broad niche tags (high volume)
- 2 - 4 specific sub-niche tags (moderate volume - where ranking is realistic)
- 1 - 2 audience/intent tags (what the target viewer follows)
Never use unrelated viral tags; misclassification hurts distribution. Keep a per-client base set + per-post variables.

## 6. Audio guidance

Recommend audio by *type and vibe* ("trending upbeat audio with a beat-drop at ~3s to sync the reveal", "original voiceover - authority content performs better with the creator's voice") - never invent specific song names as "currently trending" since trends shift weekly. Tell the user to pick from IG's trending arrow (audio with ↗) matching the described vibe, and to sync cuts to beats.

## 8. Content pillar mix (for calendars)

Balance across: **trend-riders** (30 - 40%, timely reach plays), **gap-fillers** (30 - 40%, the differentiated content from research - this is what converts viewers to followers), **evergreen authority** (20 - 30%, searchable how-tos and FAQs), and for business accounts **conversion content** (10 - 15% max - offers, proof, DM-CTA; more than that suppresses reach). Sequence calendars so trend-riders publish while trends are alive and gap-fillers build the account's "known for" identity.
